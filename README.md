# Tienda Nápoles · Landing de descarga

Página estática en HTML, CSS y JavaScript. El botón de Windows descarga
directamente el instalador 1.0.1 publicado en el repositorio offline como
archivo de la versión `v1.0.1`; no abre la página del repositorio.

El instalador publicado pesa 2.926.327 bytes y su SHA-256 es
`77B19300E767551EA8408F05B18707893D78CF6D51574F86E20091AB63D597D5`.

Para publicar una versión nueva, sube primero el instalador como archivo de una
nueva versión del repositorio offline. Después actualiza la URL de los tres
botones de descarga y el número de versión en `index.html`.

El instalador actual no tiene firma digital. Por eso la página advierte que
Windows puede mostrar una alerta de seguridad durante la instalación.
